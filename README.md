# سباق المعرفة — نسخة مباشرة (Multiplayer)

لعبة سباق عربيات تعليمية ثلاثية الأبعاد: المعلمة تفتح غرفة، الطلاب يدخلوا بالكود أو الـ QR من موبايلاتهم، وكل إجابة صح بتقدّم العربية. السيرفر هو اللي بيحسب الوقت والنقاط والترتيب.

## التشغيل على جهازك
1. نزّلي Node.js (إصدار 18 أو أحدث) من nodejs.org
2. افتحي الـ Terminal داخل فولدر المشروع:
   ```
   npm install
   npm start
   ```
3. افتحي http://localhost:3000 — دوسي "دخول المعلمة".

لو عاوزة كلمة سر للمعلمة: `TEACHER_PASSWORD=كلمتك npm start`

> الطلاب مش هيقدروا يدخلوا على localhost من موبايلاتهم. لازم تنشري المشروع على الإنترنت (الخطوات تحت).

## النشر المجاني على Render (عشان الطلاب يدخلوا من أي مكان)
1. ارفعي الفولدر على GitHub (حساب مجاني).
2. على render.com اعملي حساب → New → Web Service → اختاري المستودع.
3. الإعدادات (لو فيه ملف render.yaml هتتعبّى لوحدها):
   - Build Command: `npm install`
   - Start Command: `npm start`
4. من Environment ضيفي متغيّر `TEACHER_PASSWORD` بكلمة سر تختاريها (مهم، عشان محدش يفتح لوحة المعلمة).
5. بعد النشر هتاخدي رابط زي `https://اسمك.onrender.com` — ده الرابط اللي بتفتحيه كمعلمة، والـ QR بيتعمل منه تلقائي.

ملاحظة: الخطة المجانية بتنام بعد فترة خمول، فأول فتح ممكن ياخد نصف دقيقة. افتحي الرابط قبل الحصة بدقيقتين.

## طريقة الاستخدام
1. **بنك الأسئلة**: ضيفي/عدّلي/انسخي/احذفي الأسئلة. الأنواع: اختيار من متعدد، صح/غلط، إجابة قصيرة (تقدري تكتبي أكتر من صيغة مقبولة). لكل سؤال وقته (5/10/15/20/30/45/60 ثانية أو وقت مخصص) ونقاطه وصعوبته وتصنيفه. فيه تصدير واستيراد ملف.
2. **لعبة جديدة**: أضيفي أسئلة من البنك، رتّبيها بالأسهم، وعدّلي وقت ونقاط كل سؤال قبل البداية. اكتبي اسم اللعبة ودوسي "إنشاء" → هيطلع كود من 6 أرقام + QR + رابط.
3. الطلاب يصوّروا الـ QR، فتفتح صفحة فيها خانة واحدة بس: Enter your name، ويختاروا لون العربية ويدخلوا. مفيش كود ولا زرار "جاهز".
4. دوسي **ابدأ** → عدّ تنازلي متزامن 5 ثواني عند الجميع.
5. بعد النهاية: جدول النتائج + تصدير CSV.

## قواعد اللعبة
- الإجابة القصيرة بتتصحح تلقائيًا (بتتجاهل التشكيل والهمزات والمسافات وحروف الكبير/الصغير).
- الطالب بيعرف إجابته صح ولا غلط فورًا وعربيته بتاخد بوست، وباقي العربيات بتتحرك عند إظهار الإجابة.
- نقاط السؤال = النقاط × (٠٫٥ + ٠٫٥ × الوقت المتبقي ÷ الوقت الكلي)
- حركة عربيات الباقين بتتأخر لحد إظهار الإجابة عشان محدش يعرف صح ولا غلط من حركة غيره.
- ممنوع الدخول بعد البداية. لو الطالب فصل النت، يرجع بنفس المتصفح ويكمل.
- المستوى: ٩٠٪+ ممتاز، ٧٥٪+ جيد جدًا، ٥٠٪+ جيد، أقل يحتاج تدريب.
- أقصى عدد ٢٠٠ لاعب في الغرفة (اتجرّب ١٠٠ و١٥٠ بشكل تجريبي). الألوان ممكن تتكرر والاسم فوق العربية بيفرّق.

## نظام حركة العربيات (لـ 20–30 طالب)
- مضمار عريض (56م) فيه حارات رئيسية بينها حارات فاضية للتجاوز، وشبكة انطلاق مرتّبة بصفوف.
- الحركة بخطوة ثابتة 60 مرة في الثانية، يعني نفس الإجابة تدّي نفس التقدّم على أي جهاز.
- العربية بتعجّل وتفرمل بسلاسة، ومبتدخلش في عربية قدّامها: بتبطّأ أو بتغيّر الحارة لو الحارة المجاورة فاضية.
- الترتيب بيتحسب من التقدّم المنطقي (عدد الصح) مش من مكان العربية على الشاشة.
- أسماء الطلاب بتتخفي تلقائيًا لو اتزاحمت، وبتفضل ظاهرة لك وللمتصدّرين.
- لو الغرفة فيها أكتر من 12 لاعب، عربيات الباقيين بتتعرض بشكل مبسّط لتخفيف الحمل على الجهاز.

## ملاحظات
- بنك الأسئلة محفوظ في متصفح المعلمة (localStorage). استخدمي زر "تصدير" كنسخة احتياطية.
- الاختبار: `npm test` (يختبر بروتوكول السيرفر).
- لو الجهاز ما بيدعمش WebGL بتظهر نسخة بسيطة (أشرطة تقدم) بدل ثلاثية الأبعاد.


## نظام الطالب المنفرد + ربط Google Sheets (الأحدث)

اللعبة دلوقتي مش مباراة حية: المعلمة بتنشر لعبة واحدة ولينك واحد، وكل طالب يفتح اللينك، يكتب اسمه (Enter your name) ويختار لون عربيته، ويلعب لوحده. أول ما يخلّص، النتيجة (الاسم، النقاط، عدد الغلط، الصح، الدقة، الوقت، المرتبة) تتبعت لجدول Google Sheets.

### المعلمة
- زرار **Teacher · المعلمة** في أعلى صفحة الدخول. كلمة السر الافتراضية `1234` (غيّريها بمتغير `TEACHER_PASSWORD`).
- تبويب **إنشاء لعبة**: اختاري الأسئلة والوقت والنقاط، واضغطي **نشر اللعبة للطلاب**. يظهر لك رابط الطلاب وQR.
- تبويب **درجات الطلاب**: كل النتائج مرتبة، مع بحث بالاسم وتنزيل CSV يفتح في Excel.

### ربط الجدول (مرة واحدة)
1. أنشئي Google Sheet جديد.
2. من القايمة: **Extensions → Apps Script**، وامسحي الكود اللي موجود والصقي محتوى الملف `google-sheet/Code.gs`.
3. غيّري `TOKEN` في أول الملف لنص طويل عشوائي من عندك (ده سر الربط).
4. **Deploy → New deployment → Web app**: *Execute as: Me*، *Who has access: Anyone*. وافقي على الصلاحيات، وانسخي رابط الـ Web app.
5. في السيرفر (Hugging Face: Settings → Variables and secrets، أو Render: Environment) ضيفي:
   - `SHEET_URL` = رابط الـ Web app
   - `SHEET_TOKEN` = نفس الـ TOKEN
   - `SHEET_LINK` (اختياري) = رابط الجدول العادي، علشان يظهر زرار «فتح الجدول» في لوحة المعلمة
6. ابدئي السيرفر من جديد، وانشري اللعبة تاني.

الجدول بيحفظ كمان اللعبة المنشورة (تبويب `Game`) فمتضيعش لو السيرفر المجاني عمل restart. من غير ربط الجدول، النتائج واللعبة بيتحفظوا مؤقتًا على السيرفر بس.

## نسخة مجانية بدون سيرفر + درجات تلقائية (GitHub Pages + Google Sheet)

1. **الموقع:** من الريبو → Settings → Pages → Source: `main` / مجلد `docs`. الرابط هيبقى `https://shaimaa-alaa.github.io/Online-Game/`.
2. **الجدول:** اعملي Google Sheet جديد → Extensions → Apps Script → الصقي محتوى `google-sheet/Code.gs`، غيّري `TOKEN` و `KEY` لنصين عشوائيين طويلين مختلفين → Deploy → New deployment → Web app (Execute as: Me، Who has access: Anyone) → انسخي رابط الـ Web app.
3. **الربط:** افتحي الموقع → زر المعلمة (1234) → «درجات الطلاب» → «ربط جدول Google» → الصقي الرابط والـ TOKEN والـ KEY → «حفظ واختبار الربط».
4. **الاختبار:** اعملي اختبار → «الرابط» (لازم بعد الربط علشان الرابط يحمل بيانات الجدول). أي طالب يخلّص، اسمه ودرجته يظهروا في تبويب الدرجات وفي الجدول.

تحديث `docs/index.html`: `python3 artifact/build.py pages`.
